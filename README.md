# Knowledge Handout for Deloitte USA by Futurelab Studios

Static front-end digital debrief for the Deloitte USA AI enablement workshop.

## Local Preview

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

Open:

```text
http://127.0.0.1:8765/deloitte-ai-session-handout/index.html
```

## Netlify

This folder is deployable as a static Netlify site. The publish directory is the repository root.
