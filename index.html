Workshop debrief

The session was about changing the shape of everyday work.

The most useful AI behavior is not a one-off answer. It is a repeatable work system: clear prompts, reusable knowledge, explicit skills, fast prototypes, and a habit of reviewing outputs before they travel.

Prompting

Better prompts create better work contracts.

Role, context, rules, examples, output schema, and review criteria turn AI from a blank chat box into a governed collaborator.

Second brain

Useful knowledge should compound.

Codex can help turn notes, links, and workshop learning into a living memory layer that gets easier to query and improve.

Prototype culture

Showing beats explaining.

Vibe coding is most valuable when it turns a vague workflow into something visible enough for stakeholders to react to.

Signal 01

AI belongs inside work products.

Decks, spreadsheets, documents, research notes, and prototypes are where adoption becomes measurable.

Signal 02

Structure is the new productivity layer.

Prompt libraries, SKILL.md files, and second-brain pages make good work easier to repeat.

Signal 03

Human review remains the control point.

The best workflows preserve judgment, source trails, confidentiality checks, and explicit quality gates.

How to use the learning

Five practical frameworks from the workshop.

Each framework is intentionally short. The point is to help the Deloitte team move from inspiration to a small repeatable behavior this week.

Prompting ladder

Ask, improve the ask, then govern the output.

Use this when the task is ambiguous, high-value, or repeatable.

1

State the work product.

Memo, tracker, slide outline, spreadsheet insight, prototype, or code change.

2

Give the model a role.

Make the role specific to the audience and decision context.

3

Add a quality gate.

Ask it to flag assumptions, missing evidence, sensitivity risk, and weak logic.

Second brain method

Move from stored files to compiled knowledge.

Use this to maintain a practical Codex knowledge base.

1

Capture sources.

Notes, reports, transcripts, links, decisions, and reusable prompts.

2

Compile pages.

Turn raw material into readable pages for concepts, decisions, workstreams, and methods.

3

Review weekly.

Ask Codex to find stale claims, contradictions, missing links, and useful updates.

AI for work products

Accelerate decks, documents, and spreadsheets.

Use AI for structure, critique, cleanup, and first-pass synthesis.

1

Presentation.

Turn raw bullets into a storyline, insight titles, and suggested visuals.

2

Documentation.

Convert transcripts into decisions, actions, risks, and follow-up notes.

3

Excel.

Profile data, explain formulas, surface outliers, and prepare chart-ready insights.

Skill files

Package a repeated workflow as instructions.

A SKILL.md file makes quality portable across future Codex sessions.

1

Define trigger conditions.

When should this skill be used, and when should it not?

2

Write the workflow.

Inputs, steps, checks, expected artifacts, and safety boundaries.

3

Attach examples.

Add references, templates, and quality criteria so the skill improves the next run.
